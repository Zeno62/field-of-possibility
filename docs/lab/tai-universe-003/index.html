实验边界与算法约定

经典结构：六爻从下到上；上坤下乾为泰，上乾下坤为否。蒙为上艮下坎；蒙九二变后，下卦坤、上卦艮，为剥。这里仅做结构核对，不作占断。

本版的工程假设：以 d(g)=(2×阳爻数−3)/3 表示方向，E=max(0,(d(下)−d(上))/2) 表示相向程度。六个通路位置再检查局部爻是否满足初始结构约束。这个数值公式、爻位与通路的对应都是可替换的实验约定，不是《周易》原文或已证明的自然定律。

实做与未做：关系卦已参与高层组合；局部变更会重算共享依赖；同一绘图函数读取几何与通路，不按“泰/否”名称造形。地形轮廓仍是共同的测试载体，尚未由卦义自动推出真实山河；未实现完整五行动力学、多人持久化或第一人创世。也没有把之卦当必然下一状态。

运行：本页自含 CSS、JS 与固定预览，无 CDN、模块导入、模型文件、WebGL 或个人信息采集。三维顶点经投影后由 Canvas 2D 绘制。动画循环不改变世界；世界仅在明确的测试操作后变化。视图坐标不等于关系距离。
