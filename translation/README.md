# Translation workflow · v5.0

The Chinese v5.0 edition is the source. The official English edition uses the same publication version.

- [Chinese source](../whitepaper/zh-Hans/full/field-of-possibility-whitepaper-v5.0-zh-Hans.md)

Changes must identify the original passage, proposed wording, reason, and whether meaning changes. Knowing, Awareness and Luminosity must not be conflated with consciousness. Substantive changes require author review; no new theory is introduced by translation.
